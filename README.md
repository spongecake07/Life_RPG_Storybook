# Life RPG Storybook

A public, bilingual page-turning reader for **Chapter One: The Road Home**.

Open `index.html` in a browser or enable GitHub Pages under **Settings → Pages → Deploy from a branch → main → /(root)**.

The storybook includes English and French text and saves reading progress locally in the browser. This repository contains only the public storybook, not the private Life RPG game source.

The current story is a working narrative edition and includes proposed scenes.
